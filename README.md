# Lumacrom website

A responsive, static landing page for the Lumacrom creative studio.

## Run locally

Open `index.html` in a browser. The page uses local logo assets in `assets/` and Google Fonts via CSS import.

## Deploy with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The site can then be connected to the Lumacrom domain separately.

The portfolio artwork panels are design studies; replace them with approved project imagery and video before launch. The featured Newtopia link currently opens the existing project page.
